LANGGRAPH · EVENTS
Event import workflow · v0.9.0
local preview

        

          
START
↓

          
01
crawl
Wybrany link z katalogu wyspy jest punktem startowym. Generic crawler odkrywa URL-e eventów; Tavily może być użyte tylko do discovery, gdy agenda tego wymaga.
↓

          
02
clean
Czyści treść, zachowuje JSON-LD i deterministycznie czyta jawne pola HTML: Inicio, Finalización, Lugar i Precio. Stare daty odpadają przed LLM.
↓

          
03
extract
Priorytet: JSON-LD → jawne pola HTML → LLM. LLM tylko uzupełnia braki i nie nadpisuje dat/miejsca znalezionych w źródle.
↓

          
04
validate
Sprawdza tytuł, datę i venue. Braki trafiają do needs_review zamiast być zgadywane.
↓

          
05
human_review
Graf zatrzymuje się tutaj. Panel Events pokazuje ustrukturyzowane eventy do kontroli.
↓ approve later

          
06
publish
Na razie wyłącznie lokalny JSON export. Produkcyjne PostgreSQL pozostaje osobnym późniejszym krokiem.
↓

          
END

        

        
Wspólna infrastruktura:
Text workflow i Event Importer korzystają z tego samego LangGraph checkpointera/MongoDB, ale mają osobne state i nody. Dzięki temu eventy nie mieszają się z generowaniem artykułów.
