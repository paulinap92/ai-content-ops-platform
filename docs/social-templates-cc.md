# Canarias Cerca · Plantillas

Open Studio → Plantillas or select an editorial record → Generar gráfica. Existing official Canvas layout, original logo recovered from the accepted HTML prototype, plus AI Visual (editable adaptation of the earlier generated decorative mockup; generated Teide detail, original brand, no baked placeholder text). Five categories, including Guía; four resolutions, two styles. User supplies a photo/chart or uses the existing record image. Placeholders may be exported as templates but not stored as publication assets. PNG is generated locally. Save to existing library or create an unapproved social draft with the appropriate channel. Source identity is retained in media JSON metadata. No schema migration, external API keys, AI generation charges, or automatic publishing. For a remote image without CORS, upload a local licensed copy. Actual publishing uses the existing manual Metricool / WhatsApp workflow.
